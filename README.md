# Mhamad Hsen Rza — Portfolio Website

A personal portfolio website showcasing my work, skills, and experience as a Computer Science student and web developer. Built with a modern "liquid glass" design aesthetic featuring animated background orbs, glassmorphism cards, and smooth scroll reveals.

## Features

- 🎨 Glassmorphism UI with dynamic cursor-tracked sheen effects
- 🌊 Animated ambient background orbs
- 📱 Fully responsive layout (mobile, tablet, desktop)
- ✨ Scroll-triggered reveal animations
- 🧭 Smooth-scrolling navigation with sticky glass navbar
- 🗂️ Sections: Hero, About, Skills, Projects, Experience, Contact

## Tech Stack

- **HTML5**
- **[Tailwind CSS](https://tailwindcss.com/)** (via CDN)
- **[DaisyUI](https://daisyui.com/)** (via CDN)
- **JavaScript** (vanilla — Intersection Observer for scroll reveals, mouse tracking for glass sheen)
- **[Google Fonts](https://fonts.google.com/)** — Inter & JetBrains Mono

## Getting Started

No build tools or dependencies to install — this is a static site.

1. Clone the repository
   ```bash
   git clone https://github.com/<your-username>/<your-repo>.git
   cd <your-repo>
   ```
2. Open `index.html` directly in your browser, or serve it locally:
   ```bash
   npx serve .
   ```

## Sections

| Section | Description |
|---|---|
| **Hero** | Introduction with name, role, and quick stats |
| **About** | Short bio and location/availability info |
| **Skills** | Frontend, Backend, Design Systems, DevOps capabilities |
| **Work** | Selected/featured projects |
| **Experience** | Academic and development timeline |
| **Contact** | Email, GitHub, Instagram, and phone contact links |

## Customization

- Update text content directly in `index.html`
- Replace `hama.jpg` with your own profile photo
- Update project cards under the `#work` section with your real projects and links
- Update contact links (email, GitHub, Instagram, phone) in the `#contact` section
- Colors can be adjusted via the CSS custom properties in the `:root` block (`--blue`, `--purple`, `--pink`, `--teal`)
